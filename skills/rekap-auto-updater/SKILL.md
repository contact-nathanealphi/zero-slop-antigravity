---
name: rekap-auto-updater
description: Update the project progress / recap file concisely after a large feature or QA stage is done.
---

- Triggered when one large feature or QA stage has been verified as done.
- Find the recap / progress file at the root (`PROGRESS.md`, `HANDOFF.md`, or `rekap*.md`). Read it partially, then append a concise update (max 3–5 lines: date, feature finished, main files changed) without rewriting the whole file.
