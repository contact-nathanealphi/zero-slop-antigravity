---
name: lesson-learner
description: Record a user correction about a pattern or technical choice in LESSONS.md so it never repeats.
---

- Triggered when the user corrects a repeated mistake, a library choice, or the agent's code style.
- Append at most 1–2 lines of permanent rules to `LESSONS.md` at the project root (create it if missing) in this format: `- [Context]: Do not do X, always use Y.`
- Confirm briefly that the lesson was recorded so it is read automatically in the next session.
